# Changelog

All notable changes are documented here. The project follows Semantic Versioning while pre-1.0 interfaces remain explicitly alpha.

## 0.1.0 — 2026-08-29

### Added

- Preview-first `awc init` with project and umbrella profiles.
- Non-destructive conflict proposals and idempotent re-installation.
- Evidence-labeled doctor, recovery, handoff, snapshot, and privacy commands.
- Optional standalone Claude Code hooks for SessionStart, PostCompact, Stop, and SessionEnd.
- Synthetic project and umbrella examples.
- Deterministic release build and public-release validation.
