# Security Policy

## Supported version

The current `0.1.x` line receives security fixes while the interface remains alpha.

## Reporting

Use a private GitHub security advisory after the repository is published. Do not open a public issue containing credentials, personal paths, private workspace state, or exploitable deployment details.

## Security boundary

AWC is a continuity scaffold, not a sandbox, access-control system, secrets manager, backup system, or policy-enforcement engine. Markdown instructions guide agents but cannot guarantee compliance. Review generated files, agent actions, and hook configuration before use.
